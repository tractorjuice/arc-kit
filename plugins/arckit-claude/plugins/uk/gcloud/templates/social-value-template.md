## How Social Value Is Assessed

| Item | Rule |
|------|------|
| Weighting | 10% on every lot (1a, 1b, 2a, 2b and 3) |
| Marking | Pass/fail. A pass scores the full 10%. A fail scores 0 and disqualifies the tender |
| Section A | Five questions. Answering "No" to any of them makes the bid non-compliant |
| Section B | At least one measure must be selected, or the application is non-compliant. Selecting more measures does not score more |
| Section C | Stating that you will NOT have a Social Value Contact makes the application non-compliant |
| Operational Readiness | Six questions. Answering "No" to any of them means the bid is disregarded |
| After award | A buyer may add a social value requirement to a call-off contract and, where it is relevant and proportionate, you must meet it. Listings show the measures you selected, and buyers can filter search results by social value |

Sources: GCA question export (Supplier Declaration sheet) and Attachment 2d (Quality questionnaire) v4.0.
