ArcKit Command Reference

AI command catalogue for governed architecture work: requirements, risk, ADRs, diagrams, Wardley maps, procurement, assurance, and compliance overlays.

ArcKit AI Commands

Use this AI harness command reference to find the right ArcKit command, understand its prerequisites, and install only the core or community overlay plugins your project needs.

Popular starting points: install ArcKit, follow the step-by-step command guides, or filter this table by jurisdiction, status, category, and dependency tier.

Which plugin ships which command? ArcKit's Claude Code marketplace includes the core plugin plus regional, sector, supplier, and method overlays. The Tier column tells you whether a command ships in arckit (Core) or in a community overlay plugin:

  • Tier = Core → ships in arckit
  • Tier = Community + Jurisdiction = UAE → arckit-uae
  • Tier = Community + Jurisdiction = France → arckit-fr
  • Tier = Community + Jurisdiction = Canada → arckit-ca
  • Tier = Community + Jurisdiction = EU → arckit-eu
  • Tier = Community + Jurisdiction = Austria → arckit-at
  • Tier = Community + Jurisdiction = Australia → arckit-au
  • Tier = Community + Jurisdiction = USA → arckit-us
  • Tier = Community + Sector = UK Finance → arckit-uk-finance — payments slice (v1)
  • Tier = Community + Sector = UK NHS → arckit-uk-nhs — clinical safety + medical-device classification
  • Tier = Community + Category = UK G-Cloud Supplier → arckit-uk-gcloud — supplier-side G-Cloud 15 bid authoring and submission pack
  • Tier = Community + Category = FDE Site Generator → arckit-fde — Forward Deploy Engineering website generator
  • Tier = Community + Category = TOGAF ADM → arckit-togaf-adm — ADM lifecycle and architecture repository
  • Tier = Community + Category = AI Agent Architecture → arckit-agent-architecture — agent inventory, design, governance, integration, security, and maturity

Install only what you need: claude plugin install arckit arckit-uae picks up core + UAE. Community plugins auto-install arckit as a declared dependency. See Getting Started for install snippets.

Command names. The table shows each command as you type it in Claude Code. Core commands are /arckit:<command>. Each overlay is its own Claude Code plugin, so its commands start with the plugin's name, such as /arckit-uae:uae-pdpl. Other runtimes put core and overlay commands in one ArcKit namespace: /arckit:<command> in Gemini CLI and OpenCode, $arckit-<command> in Codex CLI, /arckit-<command> in GitHub Copilot and Mistral Vibe, and /skill:arckit-<command> in Kimi Code CLI.
