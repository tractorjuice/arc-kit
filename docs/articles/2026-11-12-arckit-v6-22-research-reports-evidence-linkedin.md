## LinkedIn Post Body

ArcKit 6.22.0 takes the verdict out of /arckit:research.

It used to score each option, rank them and say build or buy. A research report doesn't know how you want to source things and hasn't appraised value for money, so I've taken that out. It now reports what each option offers, lacks and costs, with sources, and how many products and vendors cover each capability.

/arckit:wardley decides how to source each capability. /arckit:sobc appraises value for money. /arckit:evaluate and /arckit:score score the suppliers.

It also reads prices from G-Cloud pricing documents now, so more options arrive with a real price.
