# ArcKit — UK Government Overlay

This plugin is the UK Government jurisdiction baseline for ArcKit. It will provide commands for GDS Service Standard, Technology Code of Practice, Secure by Design (NCSC CAF), DPIA (UK GDPR), AI Playbook + ATRS, G-Cloud/DOS procurement, government code reuse (govreposcrape), and UK grants.

Commands will be populated in v6.0.0 when UK-specific commands are extracted from the arckit core plugin. See the [repo root README](https://github.com/tractorjuice/arc-kit) for the ArcKit overlay model and full plugin list.

## Requires arckit core plugin

```bash
claude plugin install arckit arckit-uk
```
