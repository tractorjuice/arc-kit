# ArcKit — UK Ministry of Defence Overlay

This plugin is the UK MOD defence-sector overlay for ArcKit. It will provide commands for MOD Secure by Design (JSP 440, IAMM, CAAT continuous assurance) and JSP 936 dependable-AI assurance.

Commands will be populated in v6.0.0 when MOD-specific commands are extracted from the arckit core plugin. See the [repo root README](https://github.com/tractorjuice/arc-kit) for the ArcKit overlay model and full plugin list.

## Requires arckit core and arckit-uk

```bash
claude plugin install arckit arckit-uk arckit-uk-mod
```
